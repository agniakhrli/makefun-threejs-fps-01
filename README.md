Bastion Breach — a round-based tactical FPS: bot AI with routes and shooting, bomb plant/defuse objective at Sites A and B, buy menu with a carry-over economy, 3 weapons (Assault Rifle, Tactical Pistol, Combat Shotgun), procedural WebAudio sound effects, built on three.js 0.187.0.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
